# Inzovu App

A web application project maintained by Gad Ishimwe. This repository contains the source code for Inzovu App. The README focuses on project ownership, local development and contribution workflow.

## Development

This project is maintained in GitHub. To work on it locally, clone the repository and install its dependencies:

```bash
git clone https://github.com/gadishiimwe/inzovu-app.git
cd inzovu-app
npm install
npm run dev
```

Requires Node.js and npm. Available scripts and environment configuration are defined in `package.json` and the project source. Add any required environment variables locally; do not commit secrets.
